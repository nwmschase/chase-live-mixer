# Chase Live Mixer

Phone-friendly static live mixer: **full mix + vocals** (EQ, reverb, gains, mute/solo, Save download).

Open `/` or `/index.html` on GitHub Pages. Tap **Load**, then **Play**.

Defaults: full 0 dB, vocals −3 dB (so the vocal stem/FX cut through under the full mix), mix mids +4, master −3. Solo Vocals to verify the stem loaded.
